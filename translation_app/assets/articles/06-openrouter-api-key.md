# الحصول على مفتاح OpenRouter API

**OpenRouter** مزوّد واحد يفتح لك مئات نماذج الذكاء الاصطناعي — من OpenAI إلى Google و Meta و Mistral وغيرها — برصيد واحد ومفتاح واحد. ميزة جذابة: نماذج مجانية (`:free`) للبدء دون أي تكلفة. في هذا المقال خطوات إنشاء المفتاح ووضع رصيد إن شئت.

## الخطوة 1: أنشئ حساب OpenRouter

- افتح [openrouter.ai](https://openrouter.ai).
- سجّل الدخول — يمكنك عبر حساب Google أو GitHub أو بريد إلكتروني.
- من صفحة حسابك سترى لوحة تحكم تعرض الرصيد، واستخدامك، ومفاتيحك.

## الخطوة 2: أنشئ مفتاح API

1. انتقل إلى [openrouter.ai/keys](https://openrouter.ai/keys) (أو من حسابك ← «Keys»).
2. اضغط **«Create Key»**.
3. امنحه اسماً (مثل «Jusoor»)، ويمكنك ترك خيارات الـ Limits فارغة للاستخدام العام.
4. انسخ المفتاح الناتج — يبدأ بـ `sk-or-...` — **يُعرض مرة واحدة فقط**، فاحفظه في مكان آمن فوراً.

## الخطوة 3: الصق المفتاح في جسور

1. افتح جسور ← **الإعدادات ← مفاتيح API** ← «إضافة مفتاح».
2. سمِّه (مثل «OpenRouter») والصق المفتاح.
3. احفظ، ثم من **الإعدادات ← ملفات المزوّدين** تأكد أن ملف المزوّد من نوع **OpenRouter** مربوط بهذا المفتاح.

## الخطوة 4: اختر نموذجك

في ملف المزوّد، اكتب أي معرّف نموذج OpenRouter، مثل:

- `openai/gpt-5.6-luna` — نموذج قوي للنصوص والصور (نص+رؤية).
- `deepseek/deepseek-chat` — نموذج نصي سريع ورخيص.
- `mistralai/ministral-8b:free` — نماذج مجانية للبدء.

يمكنك استعراض [كل النماذج](https://openrouter.ai/models) وفلاترها حسب القدرات (الصور/النصوص) والسعر. معظم النماذج الجديدة غير المسماة `:free` تحتاج رصيداً على حسابك.

## الخطوة 5 (اختياري): أضف رصيداً

لتجاوز النماذج المجانية:

1. من [openrouter.ai/settings/credits](https://openrouter.ai/settings/credits) اضغط «Add Credits».
2. اختر مبلغاً (ابتداءً من بضعة دولارات) ووسيلة الدفع.
3. الرصيد يُستهلك حسب سعر كل نموذج لكل مليون رمز — النماذج الخفيفة تكلف أجزاء من السنت للترجمة الواحدة.

## لماذا OpenRouter؟

- **مزود واحد، نماذج كثيرة**: بدّل بين سونيت وجيميني وديب سيك دون تغيير الإعدادات — فقط عدّل اسم النموذج في الملف.
- **نماذج مجانية للاختبار**: مثالية لتجربة جسور أول مرة.
- **سجل استخدام موحد**: صفحة «Usage» تعرض كل طلباتك وتكلفتها بدقة.

## حل المشكلات الشائعة

| المشكلة | الحل |
| --- | --- |
| «Insufficient credits» | المفتاح المجاني لا يغطي النموذج المختار؛ استخدم نموذجاً `:free` أو أضف رصيداً. |
| «404 model not found» | تأكد من كتابة معرّف النموذج حرفياً كما في [قائمة النماذج](https://openrouter.ai/models) — بدون مسافات. |
| بطء الترجمة | بعض النماذج المجانية مزدحمة؛ جرّب نموذجاً أسرع أو «Provider Routing» الافتراضي في لوحة تحكم OpenRouter. |
