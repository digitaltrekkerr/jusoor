# الحصول على مفتاح Gemini API مجانًا

توفّر Google نماذج Gemini للمطوّرين عبر **Google AI Studio** مع طبقة مجانية كريمة — لا حاجة لبطاقة ائتمان للبدء، وإن كانت بعض النماذج تتطلب ربط حساب فوترة. في هذا المقال خطوات الحصول على المفتاح ولصقه في جسور.

## الخطوة 1: افتح Google AI Studio

- تصفّح إلى [aistudio.google.com](https://aistudio.google.com) من أي متصفح على حاسوبك أو هاتفك.
- سجّل الدخول بحساب Google الخاص بك. إن لم يكن لديك حساب، أنشئه — لا يشترط أن يكون حساب Gmail قديماً؛ أي حساب Google صالح.

## الخطوة 2: أنشئ مفتاح API

1. اضغط على أيقونة **«Get API key»** أو افتح الصفحة من القائمة [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. اضغط **«Create API key»**.
3. اختر مشروع Google Cloud الذي تريد ربط المفتاح به (يمكنك إنشاء مشروع جديد بضغطة واحدة، أو استخدام الافتراضي).
4. سيُعرض عليك المفتاح بصيغة طويلة تبدأ غالباً بـ `AIza...` — **انسخه فوراً** لأنه لا يُعرض نصاً كاملاً مرة أخرى بعد إغلاق النافذة.

## الخطوة 3: الصق المفتاح في جسور

1. افتح جسور ← **الإعدادات ← مفاتيح API**.
2. اضغط «إضافة مفتاح»، سمِّه (مثل «Gemini»)، والصق المفتاح.
3. احفظ.

ثم تأكد أن ملف المزوّد يستخدمه:

- **الإعدادات ← ملفات المزوّدين**: اختر ملف مزوّد من نوع **Gemini** واربطه بالمفتاح.
- اسم النموذج: اترك القيمة الافتراضية (`gemini-3.5-flash-lite` مثلاً) أو اكتب نموذجاً متاحاً من [نماذج Gemini](https://ai.google.dev/gemini-api/docs/models).

## ما هو «ربط حساب الفوترة» ولماذا يظهر؟

بعد 2025، تطلب Google ربط حساب فوترة في Google Cloud لبعض نماذج Gemini الأحدث — حتى مع وجود طبقة مجانية متبقية. هذا لا يعني أنك ستدفع بالضرورة:

- الرصيد المجاني يُستهلك أولاً كل يوم.
- لن تُفوتر إلا إذا تجاوزت الحد المجاني ووافقت صراحةً على الشرائح المدفوعة.
- في صفحة Google Cloud، اختر «Billing» وأضف وسيلة دفع — يمكنك ترك استهلاكك ضمن الحدود المجانية فيبقى الحساب بلا رسوم.

## حل المشكلات الشائعة

| المشكلة | الحل |
| --- | --- |
| «API key not valid» عند الترجمة | تأكد أنك نسخت المفتاح كاملاً بدون مسافات أو أسطر جديدة، وأنه من نفس حساب Google المتصل بجسور. |
| خطأ 429 (كثرة الطلبات) | الطبقة المجانية لها حدود قصوى في الدقيقة؛ انتظر ثوانٍ وأعد المحاولة، أو استخدم نموذجاً أخف مثل `gemini-3.5-flash-lite`. |
| المفتاح لا يظهر بعد الحفظ | جسور لا يعرض المفاتيح نصاً كاملاً لأسباب أمنية — تحقق أن الملف المزوّد مربوط بالمفتاح الصحيح بالاسم. |
