# الإعداد من الصفر: المزود، القالب، ومفتاح API

كيف تحصل من نقطة الصفر على أول ترجمة في جسور؟ تحتاج ثلاثة أشياء: **مزوّد ترجمة** (الجهة التي تشغّل نموذج الذكاء الاصطناعي)، **قالب ترجمة** (تعليمات النظام التي توجه النموذج)، و**مفتاح API** (بطاقة الدخول إلى المزوّد). في هذا المقال نربطها كلها معاً خطوة بخطوة.

## الخطوة 1: أضف مفتاح API

افتح **الإعدادات ← مفاتيح API** واضغط زر إضافة مفتاح جديد:

- سمِّ المفتاح باسم واضح (مثل «OpenRouter الأساسي» أو «Gemini المنزلي»).
- الصق قيمة المفتاح من صفحة المزوّد (راجع المقالين 5 و6 لكيفية الحصول على مفتاح Gemini وOpenRouter).
- احفظ التغيير. المفتاح يُخزَّن في التخزين الآمن المشفّر على جهازك، ولا يُعرض نصاً كاملاً مرة أخرى.

## الخطوة 2: أنشئ ملف مزوّد (Profile)

المزوّد هو «حساب الاتصال» الذي يربط مفتاحك بنموذج معين:

1. من **الإعدادات ← ملفات المزوّدين** اضغط «إضافة مزوّد».
2. اختر نوع المزوّد: **OpenRouter** أو **Gemini** أو **OpenAI** أو **متوافق مع OpenAI** (للواجهات المحلية مثل Ollama و LM Studio).
3. اربط المفتاح الذي أنشأته في الخطوة 1.
4. اكتب اسم النموذج (مثال: `openai/gpt-5.6-luna` لمزوّد OpenRouter، أو `gemini-3.5-flash-lite` لنماذج Gemini).
5. إن كان المزوّد يدعم الصور، اختر **نموذج رؤية** (Vision Model) — وإذا تركته فارغاً سيُستخدم نفس نموذج النص.
6. للمزوّدات المخصصة: ضع **رابط نقطة النهاية (Base URL)** — ويجب أن يبدأ بـ `https://` ما لم يكن عنواناً محلياً مثل `http://localhost:11434`.

## الخطوة 3: أنشئ قالب الترجمة

القالب يحدد *كيف* يترجم النموذج — النبرة، المجال، تنسيق المخرجات:

1. من **الإعدادات ← قوالب الترجمة** اضغط «إضافة قالب».
2. اختر ملف المزوّد الذي أنشأته.
3. اكتب **نص تعليمات النظام (System Prompt)**: «أنت مترجم محترف. ترجم {{target_language}} بدقة مع الحفاظ على صياغة Markdown».
4. حدد ما يدعمه القالب: نص، صورة، أو كلاهما.
5. اختر لغة الهدف إن كانت ثابتة — أو اتركها حرة ليقدّر النموذج لغة النص الأصلية.

## الخطوة 4: عيّن القالب كقالب افتراضي

- افتح **الشاشة الرئيسية** واختر القالب الجديد من قائمة القوالب العلوية.
- عيّن **لغة الهدف** من القائمة المنسدلة.
- اضغط «ترجمة» وسترى النتيجة تتدفق داخل التطبيق.

## الخطوة 5 (اختياري): ملف بديل (Fallback)

من **الإعدادات ← ملفات المزوّدين** يمكنك تعيين **ملف بديل**: إذا فشل المزوّد الأساسي (خطأ في المفتاح، انقطاع خدمة، نموذج غير متاح)، يتولى الملف البديل الترجمة تلقائياً. مفيد جداً للاعتمادية — اجعل مزودين مختلفين بمفتاحين مختلفين.

## تلخيص سريع

| المكوّن | أين تجده | دوره |
| --- | --- | --- |
| مفتاح API | الإعدادات ← مفاتيح API | بطاقة الدخول للمزوّد |
| ملف مزوّد | الإعدادات ← ملفات المزوّدين | يربط المفتاح بالنموذج ونقطة النهاية |
| قالب | الإعدادات ← قوالب الترجمة | يحدد أسلوب الترجمة وتعليمات النظام |
| القالب المحدد | الشاشة الرئيسية | ما يعمل فعلياً عند الضغط «ترجمة» |

بهذا تكون جاهزاً. لتفعيل النافذة العائمة فوق التطبيقات، راجع مقال «كيفية استخدام overlay الترجمة على أي تطبيق».
