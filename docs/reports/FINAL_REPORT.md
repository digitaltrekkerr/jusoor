## 2) النتائج الحرجة / العالية (تُصلَح أولاً)

### 🔴 C1 (حرج، انحدار V2) — OpenRouter: كل ترجمة نصية تفشل بـ FormatException
- **الموضع:** `packages/translation_core/lib/src/providers/openrouter_provider.dart:167-172`
- V1 كان يستخدم `buildVariableMap` (مع `jsonEscape`)؛ V2 بدّله إلى `buildRawVariableMap` ثم `jsonDecode`. المطالبة المدمجة تحوي `"` (مثل `Never say "I'm ready"`) وأسطراً جديدة → JSON مكسور قبل أي طلب شبكة.
- **أدلة الجهاز:** في الرئيسية، وعبر النافذة العائمة نفسها، ظهر الخطأ حرفياً:
  `Error: FormatException: Control character in string (at character 157) ... expert translator. Your sole function is to translate content into Arabic.`
- لا تأثر بمفتاح/نموذج؛ كل قالب نصي يمرّ عبر OpenRouter يموت جانبياً (0 طلبات شبكة كلفت).
- **العلاج المقترح:** إعادة القالب الغير-رؤي إلى المسار البرمجي (مثل `_buildVisionBody`) أو استخدام `buildVariableMap` المهرَّبة. (Gemini وOpenAI-compatible غير مصابين.)

### 🔴 H1 (مرتفع) — مفاتيح `enableThinking` و`stream` لكل قالب **ميتة**
- **الموضع:** `translation_app/lib/providers/translation_provider.dart:152-162`، `home_screen.dart:181-187`، `main.dart:684-691`، `overlay_handlers.dart:187-194` — لا أحد ينسخ `template.enableThinking/stream` إلى الـ `TranslationRequest`؛ الويـر دائماً `stream=true` و`thinking` دائماً off رغم المفتاح.
- الأدلة: حفظ/إعادة فتح المفتاح يعمل (ثبات ✓)، لكن سلوك الواجهة الخارجة لا يتغير. مؤكد بالقراءة + يخالفه تعليق 0ec39fa نفسه.

### 🟠 H2 (مرتفع) — السجل لا يظهر الترجمات الجديدة (خلل تحديث حي)
- **الموضع:** لا `invalidate/refresh` لـ`historyListProvider` بعد الحفظ (`translation_provider.dart:309-314`)، و`app.dart:133-137` (IndexedStack) لا يعيد تحميل عند تبديل التبويب، والحالة الفارغة بلا `RefreshIndicator` (`history_screen.dart:301-302`).
- **أدلة الجهاز:** بعد ترجمتين ناجحتين حفظتا في SQLite (تحققتُ بصفّين عبر sqlite3)، بقيت شاشة "السجل" تعرض "لا يوجد سجل"؛ التجديد يظهرهما بعد إعادة تشغيل التطبيق (البيانات سليمة، العرض فقط قديم).

### 🟠 H3 (متوسط-مرتفع) — السباق في حذف ملفات المشاركة المؤقتة (.md)
- `finally` يحذف الملف فور إغلاق ورقة المشاركة (`home_screen.dart:348-398`، `history_detail`، `main.dart:507-529`). التحقق على الجهاز: الملف موجود (75 بايت) أثناء ورقة المشاركة، ويختفي فور إغلاقها — أي هدف (Drive/Gmail/ملفات) قد يلتقط ملفاً محذوفاً.

### 🟠 H4 (متوسط-مرتفع) — سباق/ثغرة أمان محتملة
- `MainActivity` مَصدَّرة (`exported=true`) وتقبل `show_overlay_direct` (**F1 سيكيورتي**): أي تطبيق يستطيع فتح نافذة الترجمة+تعتيم فوق شاشة الضحية (انتحال/إزعاج). مؤكد وظيفياً (شغّلتها بنفسي عبر هذه الـ extra).
- معالج الروابط في Markdown يفتح أي scheme دون allowlist (`markdown_view_helpers.dart:13-28`) — `intent://`/mailto تفتح بلا تأكيد.

## 3) نتائج متوسطة / منخفضة

- **M1 R6 × 'auto':** عند تفعيل "لغة إخراج ثابتة" على القوالب المدمجة التي تبني `{{target_language}}`، يُمرَّر `target='auto'` → النموذج يعيد النص المصدر كما هو بلا ترجمة (أُثبت على الجهاز: أخرج الجملة الإنجليزية نفسها). يحتاج قرار تصميم (تعطيل الاستبدال عند الثبات أو مطالبة تُخبز اللغة فعلاً).
- **M2 نصوص عربية مكتوبة حرفياً:** ورقات النسخ/المشاركة تستخدم نصوصاً مدمجة (`نسخ كنص عادي`، `مشاركة كـ Markdown` …) بينما مفاتيح ARB الـ14 الجديدة غير مستخدمة → مستخدم الإنجليزية يرى عربياً.
- **M3 `OpenRouterCapabilities` ميت:** التصدير موجود لكن لا شيء يستورده، ولا "TTL 7 أيام" حقيقياً (كاش في الذاكرة بلا انتهاء).
- **M4 زوج التفكير المُرسل:** `reasoning:{effort:'low'}` يُرسل لكل نماذج OpenRouter عند `enableThinking` بلا تحقق من قدرة النموذج.
- **M5 ثيم الأوفرلاي يُقرأ مرة واحدة عند إقلاع محرك النافذة** — تغيير السمة لا يعيد تلوين النافذة إلّا بعد إعادة التشغيل (والوميض: أول إطارات بـ system ثم ينقلب).
- **M6 نافذة الأوفرلاي (in-app buttons)** لا تتحقق من `outputLanguageFixed` بينما مسار IPC يرفضه — عدم اتساق (main.dart مقابل overlay_handlers.dart).
- **M7 نشوء مضاعف لتنظيف Markdown:** Dart وKotlin بقواعد مختلفة (Kotlin لا يقدر المتداخل/backtick داخل كود) — قد يختلف المحتوى المنسوخ بين المسارين.
- **L1** إشعارات إنجليزية مخالفة للغة العربية في بعض الشاشات (API Keys، History/Template/Profile screens) — اتساق لوزاني.
- **L2** فحص التحديثات: يتجاهل عن قصد وسوم `build-<sha>`، فلا يظهر بانر إلّا بنشر بـ semver حقيقي — سلوك مقصود لكن قد يبدو "معطلاً".
- **L3** `_supportsThinkingConfig` لا يطابق `gemini-2-5-pro` (بحروف بدون نقطة) — حالة نادرة.
- **L4** الأولوية: قراءة `imageReader.acquireLatestImage()` بلا حماية null (تنويه الأمان).

## 5) ما لا يمكن التحقق منه على redroid (يحتاج جهازاً حقيقياً أو قراراً)

1. **منتقي استيراد الملفات داخل التطبيق** — مستكشف ملفات redroid يفتح الملف بدل إرجاعه للنقلى (قيود بيئة). تحقق من `رفع ملف` (docx/pdf/epub/txt) على هاتف حقيقي.
2. **جودة ترجمة OpenRouter** — لن تظهر إلّا بعد إصلاح C1؛ عندها جرّب `mistral-small-24b-instruct-2501` و`tencent/hy-mt2-1.8b` (كلاهما يعمل ورخيص) وانسَ نماذج `:free` (429 متكرر).
3. **سلوك فحص التحديثات مع نشر semver حقيقي** — انشر release بعنوان `v0.1.x` لرؤية البانر فعلياً.
4. **Screenshot/لقطة MediaProjection على Android 14/15 حقيقي** (عتبة الأذونات المختلفة)، واستهلاك البطارية والأداء.
5. **قرار تجاري:** هل يبقى سلوك R6 "إخفاء منتقي اللغة مع تمرير auto" مقبولاً أم يُصحَّح؟
6. **Q**: هل المستودع `digitaltrekkerr/jusoor` هو المقصود لنشر CI؟ CI معدّ لنشر 3 APKs لكل ABI (تغيير 41ad43d) — يُرسل `jusoor-<abi>.apk`.
