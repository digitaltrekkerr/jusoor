# Security Policy

## Supported Versions

Jusoor is pre-1.0. Only the latest code on `main` (and tagged releases cut
from it) receives security fixes.

| Version | Supported |
|---------|-----------|
| `main`  | ✅        |

## Reporting a Vulnerability

Please report vulnerabilities via **GitHub private vulnerability reporting**:
open this repository → **Security** tab → **Report a vulnerability**.

Do **not** open a public issue for security reports.

## What to Include

- The package/file or screen affected.
- Step-by-step reproduction and impact assessment.
- A suggested fix, if you have one.

Please never paste real API keys, tokens, or other secrets into any issue.

## Response & Disclosure

- We aim to acknowledge reports within **72 hours**.
- Fixes land on `main`; coordinated disclosure follows once a fix is merged.

## Background

A security audit of the codebase was performed before publication and
found no embedded secrets in tracked sources.
